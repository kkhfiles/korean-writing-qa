# Runs

**검사 실행 기록** — 입력 목록·도구 버전·설정·원시 결과·요약 보관

- **실행 구분**: 실행별 별도 디렉터리
- **재현 정보**: 입력 파일 해시 · 도구 해시 · 실행 설정
- **규칙 수집**: `claude-korean-rules-*`에 검색 범위·중복 수·후보 문단 수 기록
- **외부 도구 비교**: `external-tools-*`에 고정 커밋·검사 범위·검출 묶음·사람 판정 기록
- **회수율 측정**: `eval-*`에 라벨 출처·층별 정탐·판정 불가·오탐·규칙 후보 채택 여부 기록 (`scripts/eval_detectors.py`)
