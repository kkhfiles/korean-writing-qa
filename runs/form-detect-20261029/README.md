# 형식을 적지 않은 문서의 판별 조건 측정

**판별 조건과 그 근거** — 형식 미선언 문서를 산문인지 판별하도록 기본을 바꾸면서(2026-10-29 사용자 결정) 조건마다 산문으로 판별되는 문서 수를 집계한 기록

- **측정일**: 2026-10-29
- **방법**: 문서마다 형식 선언을 뺀 임시 사본을 개조식 모드로 검사해 산문 비율(본문 줄 가운데 목록, 표, 제목이 아니면서 문장 부호로 끝나는 줄의 비율)과 서술형 종결 수를 구하고, 조건 후보마다 산문으로 판별되는 문서 수를 집계
- **본문 보관**: 문서 원문과 이름은 저장소 밖에 두고 이 기록에는 수만 적음
