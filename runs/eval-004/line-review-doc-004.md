# 줄 단위 판정 — doc-004

**한글 23행이 바르게 쓰였는지 판정 요청** — **「② 빠진 것 찾기」의 15행이 본 일** · ①은 이미 나온 지적 10건이 맞는지 보는 것 · 빈 칸은 「고칠 데 없음」으로 읽음

## 이 판정으로 얻는 것

- **지금 세는 것**: 누군가 알아챈 문제뿐 — 검사기가 놓친 것은 안 세어짐
- **판정 뒤에 셀 수 있는 것**: 문서에 실제로 있는 문제 대비 검사기가 잡는 비율

## 쓰는 법

| 어느 표 | 묻는 것 | 판정 칸에 적을 것 |
|---|---|---|
| ① 지적 확인 | 이 지적이 맞나 | 맞으면 `O` · 아니면 `X` · 헷갈리면 `?` |
| ② 빠진 것 찾기 | 어색한 데가 있나 | 어색한 **구절을 그대로** 적음 · 없으면 빈 칸 |

**②의 보기** — 「멀티 에이전트 환경에서 세션 간 비동기 메시지 전달」 같은 줄이 걸린다면 판정 칸에 `비동기 메시지 전달` 이라고만 적으면 됨 · 고칠 말까지는 안 적어도 됨

**대상 아닌 것** — 굵게·이모지·강조 개수는 이 검사가 보는 축이 아님 · 한글 어절 4개 미만인 줄(제목·제품명·날짜·출처)은 목록에서 뺌
