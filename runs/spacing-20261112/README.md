# 1층 맞춤법에 더한 꼴 — 붙여 쓴 의존 명사와 「안」, 「다음 주」, 보이지 않는 글자 (2026-11-12)

**결론** — 업무 소개 글 36편을 두 모델이 읽어 찾은 1층 빈틈 가운데 글자와 형태소로 갈리는 꼴을 더함. 사람이 쓴 글 237편에서 새로 걸린 곳 18건이 모두 실제 띄어쓰기 오류였고 오탐은 0건(「안」 규칙을 좁히기 전에는 「안내」를 잘못 읽어 5건)

## 더한 것

| 꼴 | 등급 | 보기(지어낸 문장) |
|---|---|---|
| 관형형 어미에 붙여 쓴 의존 명사 「것」, 「거」, 「줄」과 「때」 | 오류 | 「아실겁니다」, 「동작한게」, 「열었을때는」 같은 꼴 |
| 「하다」, 「되다」 앞에 붙여 쓴 부정의 「안」 | 주의 | 「안하겠습니다」, 「안되는」 같은 꼴 |
| 「다음주」, 「이번주」, 「수 많은」 | 오류(맞춤법 목록) | 「다음주 화요일」 같은 꼴 |
| 낱말이나 주소에 붙은 폭 없는 글자(U+200B, U+FEFF 등) | 오류(혼자 떨어져 있으면 주의) | 링크 끝에 붙은 U+FEFF |
| 마침표 뒤에 겹친 느낌표나 물음표 | 주의 | 「안녕하세요.!」 같은 꼴 |
| 의문 라벨의 「어떤」 | 오류(의문문 라벨) | 「어떤 업무에 쓰나」 같은 라벨 |

## 넣지 않은 것

- **「데」** — 형태소 분석기가 연결 어미 「-는데」(「좋은데 나가자」)도 의존 명사로 읽음
- **「중」** — 「진행중」은 띄어 쓰는 것이 맞지만 「그중」, 「도중」, 「부재중」처럼 한 낱말로 굳은 것이 많음
- **「-ㄹ걸」, 「-ㄹ게」** — 어미라 「할게요」, 「갈걸」을 의존 명사로 읽지 않게 뺌(「할게 많다」는 놓침)
- **「엑셀」과 「액셀」** — 문맥을 봐야 갈림

## 방식

- **오탐 점검** — 업무 공지와 규정 201편, 업무 소개 글 36편(모두 사람이 씀, 저장소 밖)에서 새 규칙이 걸린 곳을 모두 읽음
- **「다음 주」 실측** — 같은 글에서 「이번 주」 31, 「이번주」 2, 「다음 주」 10, 「다음주」 1
- **보이지 않는 글자** — 사람 글 201편에서 U+FEFF 8건(대부분 빈칸 사이) → 낱말에 붙은 것만 오류
- **시험** — `tests/test_spacing_invisible.py`(잡을 꼴과 잡으면 안 될 꼴), 대장 F-210~F-216
