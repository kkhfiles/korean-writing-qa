# 사전 기록 — 연구에서 쓴 문서 단위 지표가 업무 문서의 AI 글을 가르나 (2026-11-09)

**물음** — 한국어 AI 글 판별 연구(KatFishNet ACL 2025, arXiv 2610.22940)가 차이를 보인 지표를 문서 단위 주의로 단어 점검에 넣을 근거가 있나

## 입력

- 사람 업무 문서 — `runs/compare-imnotai-20261023/measure.py` 와 같은 284편(2023년까지 고친 노션, 제품 문서, 사내 규정, 설계 문서)
- AI 업무 문서 — 같은 측정의 238편(`data/raw` 진단 표본과 지시문 실험 산출물)
- 한글 300자 이상, 코드 블록 제외

## 지표

| 지표 | 정의 | 연구 근거 |
|---|---|---|
| 형식적 접속어 밀도 | 문장 첫머리 「따라서, 또한, 즉, 그러므로, 게다가, 아울러, 나아가, 더불어, 결과적으로, 이처럼, 이에 따라, 한편, 반면, 무엇보다」 수 / 한글 1천 자 | dm_formal_ratio |
| 형식적 접속어 비율 | 위 수 / (위 수 + 「그리고, 그래서, 그런데, 하지만, 그러나, 근데」 수) | dm_formal_ratio |
| 쉼표 문장 비율 | 쉼표가 있는 문장 / 전체 문장 | KatFishNet 쉼표 사용 |
| 보조용언 다양성 | Kiwi VX 원형의 종류 수 / VX 수(VX 5개 이상인 문서만) | vx_diversity |
| 의존 명사 띄어 씀 비율 | 앞이 빈칸인 NNB / 전체 NNB | space_ratio_nnb |
| 문장 길이 변동 계수 | 문장 글자 수의 표준편차 / 평균 | 일반 AI 글 지표(대조용) |

## 가름(결과를 보기 전에 정함)

- **후보가 되는 조건** — AUC(AI 문서 값이 사람 문서 값보다 클 확률)가 0.70 이상이거나 0.30 이하이고, 문서를 무작위로 반씩 나눈 두 묶음에서 방향이 같음
- **후보가 없으면** — 단어 점검에 넣지 않고 기록만 남김
- **후보가 있어도 바로 넣지 않음** — 사람 문서가 2023년 문서라 문체 기준(합쇼체, 개조식)이 달라 생긴 차이일 수 있음(2026-10-23 측정에서 우리 검사기가 사람 문서를 더 지적한 까닭). 후보 지표는 그 지표가 가리키는 문장을 사람이 읽어 「고칠 곳인가」를 따로 판정한 뒤 정함
- **판별과 교정은 다름** — AI 글을 가르는 지표라도 고칠 곳을 가리키지 않으면 넣지 않음
