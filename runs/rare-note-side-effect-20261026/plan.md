# 드문 낱말 목록이 헛짚음에 미치는 영향 — 실험 전 기록

**목적** — 판정기에 추가한 드문 낱말 목록(2026-10-23)이 정상 낱말을 고칠 것으로 지적하는 헛짚음을 늘리는지 확인함

- **측정일**: 2026-10-26
- **문서**: 드문 낱말이 많은데 짧은 실제 문서 셋(한글 약 4천 자, 드문 낱말 42개)
  - 이 저장소 `CONTRIBUTING.md`(28개)
  - DevRel 회의록(8개)
  - 주간보고 한 장 요약(6개)
- **두 판**: 목록을 추가한 현재 판정기와 목록을 제거한 판정기를 판마다 3회씩 번갈아 호출함(추가, 제거, 추가 …)
- **판정기**: `probe.run_arm`(guided, Opus, 구독)이고, 목록을 제거한 판은 `probe.rare_note` 를 빈 문자열로 바꿔 호출함
- **본문 보관**: 지적 원문은 저장소 밖 작업 폴더에만 보관하고 저장소에는 집계만 기록함

## 미리 정한 판정 기준

- **같은 지적**: 같은 문서, 같은 줄이고 지적한 표현 중 한쪽이 다른 쪽을 포함함
- **안정된 지적**: 한 판의 세 회차 중 두 번 이상 나온 지적
- **목록이 더한 지적**: 목록을 추가한 판에서 안정되고 목록을 제거한 판에서는 한 번 이하로 나온 지적(반대 방향은 「목록이 없앤 지적」)
- **사람 판정**: 목록이 더한 지적마다 「고칠 것인가, 헛짚음인가」를 사용자가 판정함
- **결과에 따른 조치**
  - 목록이 더한 지적 가운데 헛짚음이 고칠 것으로 판정한 지적보다 많으면 목록 문구를 고칠지 목록을 제거할지 사용자와 정함
  - 그렇지 않으면 현재 목록을 유지함
  - 목록이 더한 지적이 0건이면 부작용 없음으로 기록
