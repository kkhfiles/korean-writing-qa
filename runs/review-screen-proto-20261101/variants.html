검토 화면 시안 다섯

검사기와 판정기가 제안한 수정을 사람이 선택하는 화면 — 판정표를 대신할 도구의 시안 다섯 개 (자료는 가상 회사 채용 공고 초안에 1층 검사기와 2층 판정기가 실제로 낸 지적 18건이며, 다섯 시안은 같은 선택 상태를 공유함)

  • 선택하면 파일에 바로 반영선택한 결과를 서버가 문서에 바로 저장함 — 세션이 지적마다 파일을 열어 수정하는 데 드는 토큰이 없음
  • 사람이 고른 줄은 다시 판정하지 않음지금 규칙 그대로 — 재판정 호출은 「세션에 맡김」을 선택한 줄에서만 발생함. 10월 실사용 판정 1,697회에서 나온 지적 가운데 73%가 재판정에서 새로 나왔으므로, 재판정 호출을 줄이면 세션이 처리할 지적도 줄어듦
  • 세션 의견 칸을 기본으로 두지 않음지금 판정표는 세션이 지적마다 「제 의견」을 써서 건수만큼 출력 토큰이 듦 — 판정기 수정안을 기본값으로 표시하고, 의견은 사람이 원할 때만 요청
  • 세션에는 요약만 전달제출하면 세션이 받는 것은 집계 한 줄과 맡긴 지적뿐 — 화면 아래 고정 줄의 「세션이 받을 요약」 버튼으로 실제 내용을 확인할 수 있음
