# 검토 화면 시안

**검사기가 제안한 수정을 원문 위 diff로 보고 하나씩 반영하는 화면의 시안** — 결정 대기 항목은 [판단이 필요한 것](../../docs/decisions-pending.md)의 「외부 비교 측정과 검토 화면」 절

- **만든 날**: 2026-11-01
- **계기**: 사용자 제안(2026-11-01) — 처음 쓰는 사람이 백서 검토 때의 수정 표시 HTML처럼 고친 곳을 보고 가치를 확인하고, 신뢰할 수 있는 갈래는 확인을 건너뛰고, 애매한 것과 개인 규칙은 직접 반영하게 함
- **배경**: [외부 비교 측정](../bench-external-20261031/README.md)에서 1층과 2층 지적을 AI가 사람 확인 없이 반영한 초안이 판정 모델 세 개 모두에게서 더 낮은 평가를 받았고, 원인은 새 정보가 있어야 고쳐지는 지적을 고치며 정보를 지어낸 것
- **상태**: 시안(고른 결과는 페이지 안에서만 바뀜). 사용자 확인 뒤 실제 도구로 개발할 예정

## 화면 구성

| 부분 | 표시와 동작 |
|---|---|
| 요약 줄 | 세 묶음별 지적 수와 처리 상태별(미처리, 반영, 직접 고침, 그대로 둠) 지적 수 |
| 원문 diff | 바로 반영할 수정은 삭제와 추가, 작성자 확인은 노란 점선, 문체 규칙은 물결선. 번호를 누르면 카드로 이동 |
| 바로 반영할 수 있는 표현 | 반영, 그대로, 직접 고침, 규칙으로 남기기. 갈래마다 「앞으로 묻지 않고 반영」 스위치 |
| 작성자 정보가 필요한 지적 | 판정기의 확인할 사실을 질문으로 표시하고 입력 칸을 둠. 판정기 수정안은 접어 두고 「맞는지 확인했고 이 수정안 씀」으로만 반영 |
| 사용자 문체 규칙 | 직접 고침, 그대로. 「이 종류 글에는 이 규칙을 쓰지 않음」 스위치 |
| 남긴 규칙 | 「내 규칙」 또는 「팀 공통 후보」로 범위 선택 |
| 반영한 문서 | 고른 대로 반영한 최종 문서와 복사 버튼 |

- **묶음 나누기**: 2층 지적 중 확인할 사실이 있거나 사람 확인으로 넘어온 것은 「작성자 정보 필요」, 나머지는 「바로 반영」. 1층의 서술형 종결 계열은 「문체 규칙」
- **신뢰 스위치 제한**: 작성자 정보가 필요한 지적에는 켤 수 없음 — 고침 횟수로 자동 전환하던 코드를 삭제한 결정(2026-10-12)과 같은 이유

## 시안 자료

- **문서**: 외부 비교 측정의 D3 초안 6번(가상 회사 채용 공고, AI 작성)
- **지적**: 공개판 기본 설정의 1층 지적과 그 초안의 2층 1회차 판정 — 바로 반영 4건, 작성자 확인 8건, 문체 규칙 6건
- **보관**: 생성한 시안은 저장소 밖 `~/.local/share/korean-writing-qa/bench-external/review-proto/`

## 확인한 것

- **버튼 동작**: `click_test.py` 로 반영, 갈래 신뢰, 직접 채움, 문체 규칙 끄기, 규칙 남기기를 눌러 최종 문서와 규칙 목록이 바뀌고 페이지 오류가 없음을 확인
- **화면**: 폭 다섯 가지에서 가로 넘침 없음, 글자와 배경의 색 대비 최솟값 5.36:1, 휴대폰 폭 버튼 높이 44px
- **재현**: 이 폴더의 `make_proto.py` 로 다시 생성한 결과가 발행한 시안과 같음

## 실제 도구로 만들 때 더할 것

- **파일 반영**: 반영한 결과를 원본 파일에 저장
- **답 기록**: 선택한 답을 판정 기록에 추가해 다음 판정에 반영
- **신뢰 설정 저장**: 켠 갈래는 다음 문서부터 반영한 상태로 표시하고 되돌리기만 허용
- **규칙 저장**: 「내 규칙」은 개인 규칙 파일에, 「팀 공통 후보」는 규칙 후보 표에 추가
