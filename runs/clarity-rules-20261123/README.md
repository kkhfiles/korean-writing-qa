# 명료성 규칙 넷 반영 전후 측정

**AI 글의 명료성 결함 셋을 다룬 공개 글에서 고른 2층 규칙 넷의 회수와 오탐** — 판정 기준은 결과 확인 전에 작성(측정 결과 위치: 「결과」 절)

## 출처와 바꾼 규칙

- **출처 글**: zonderlabs 「AI slop」 글(https://zonderlabs.com/slop) — Williams 『Style: The Basics of Clarity and Grace』의 원칙으로 결함을 셋으로 나눔(행위자와 행동을 감춤, 모호한 표현, 내용 없는 문장과 엇나간 강조)
- **출처 글의 수치**: 불명확한 문장 비율(AI 기사 54%, 사람 기사 10%)은 표본 크기와 판정자 일치도를 밝히지 않아 근거로 쓰지 않음
- **이미 있던 규칙**: 번역투의 「이루어지다」 피동, 추상 명사로 감싼 서술, 사물 주어, 막연한 비유(`경로`, `자리`, `세우다`)
- **새로 넣는 갈래**: 「행위자를 감춘 명사 주어」, 「결론을 뒤에 둔 보고 문장」, 「부정과 예외를 겹친 문장」, 「처리 순서를 공간 위치로 쓴 말」
- **반영 위치**: `finalize-korean-document` 9단계 항목과 `core-rules.md` 원칙 한 줄

## 측정 방법

- **비교 대상**: 바꾸기 전 규칙(커밋 `9239654`)과 바꾼 뒤 규칙(작업 트리)
- **탐침**: `scripts/probe_layer2_discourse.py` — 판정기와 같은 프롬프트, Opus, 구독 호출
- **운반 문서 1**: `tests/fixtures/layer2-discourse/cases.jsonl` 로 조립한 문서 — 기존 사례 22건(D-01~D-22)과 새 사례 16건(D-23~D-38, 결함 8건과 같은 말을 쓴 정상 짝 8건)
- **운반 문서 2**: 기존 2층 탐침 문서(`tests/fixtures/layer2-kinds/carrier.md`) — 대장의 2층 몫과 예비 예문
- **반복**: 운반 문서 1은 규칙마다 2회, 운반 문서 2는 규칙마다 1회
- **새 사례의 성격**: 출처 글의 결함 꼴을 따라 새로 지은 문장 — 사람이 짚은 원문이 아니므로 못 잡았을 때의 무게가 대장보다 가벼움

## 사전 판정 기준

**판정** — 아래 다섯 기준을 모두 통과하면 「반영」, 하나라도 미달이면 「보류」(합계는 운반 문서 1의 두 회를 더한 값)

| 기준 | 지표 | 넘는 조건 |
|---|---|---|
| 새 사례 회수 비악화 | 새 결함 사례 줄 회수(16번 중) | 바꾼 뒤가 바꾸기 전 이상 |
| 새 정상 짝 보존 | 새 정상 짝 줄에 새 갈래 이름으로 낸 지적 | 바꾼 뒤 1건 이하 |
| 정상 짝 보존 | 정상 짝 전체(19쌍)에 낸 지적 줄 수 | 바꾼 뒤가 바꾸기 전보다 2 이하로 많음 |
| 기존 사례 회수 비악화 | D-01~D-22 결함 사례 줄 회수(22번 중) | 바꾼 뒤가 바꾸기 전보다 2 이하로 적음 |
| 대장 회수와 지적 수 비악화 | 운반 문서 2의 대장 2층 몫 회수(줄)와 심지 않은 곳 지적 수 | 회수는 2 이하로 적음, 지적 수는 바꾸기 전의 1.2배 이하 |

- **회수 증가는 반영 조건이 아님** — 외부 규칙은 넣는 것이 기본이라(`AGENTS.md` 「판단이 갈릴 때」), 해치지 않으면 넣음. 증가 폭은 참고로 적음
- **재판정 변동**: 같은 입력 재판정 시 지적 수 평균 16% 변동(2026-09-30 실측)
- **회차 한계**: 두 회차로는 작은 차이 판정 불가

## 결과

**판정 — 「반영」**: 다섯 기준 모두 통과(대장 회수는 허용 폭 2에 딱 닿아 여유 없음)

| 지표 | 바꾸기 전 | 바꾼 뒤 | 기준 |
|---|---|---|---|
| 새 결함 사례 줄 회수(두 회 합계, 16번 중) | 14 | 16 | 통과 |
| 새 정상 짝 줄에 새 갈래 이름으로 낸 지적 | 0 | 0 | 통과 |
| 정상 짝 전체에 낸 지적 줄 수(두 회 합계) | 3 | 1 | 통과 |
| 기존 결함 사례 줄 회수(두 회 합계, 22번 중) | 22 | 22 | 통과 |
| 대장 2층 몫 회수(줄, 한 회) | 127 | 125 | 통과 |
| 운반 문서 2의 심지 않은 곳 지적(한 회) | 19 | 13 | 통과 |

- **바꾸기 전 회수의 성격**: 새 결함 8건 중 7건은 다른 갈래 이름으로 이미 짚음 — 행위자 사례는 「번역투 줄이기」, 보고 문장은 「기계적 병렬 피하기」, 겹친 부정은 「수식 범위와 부정 범위」와 「소리 내어 읽기」
- **바꾸기 전에 놓친 것**: 「앞단, 캐시 조회 이전 계층에 놓입니다」(D-35) 두 회 모두 — 이미 있던 「막연한 비유 줄이기」가 이 꼴을 덮지 못함
- **바꾼 뒤 회수의 성격**: 짚은 16건 모두 새 갈래 이름으로 짚음 — 줄 회수 증가는 2건이고, 나머지 이득은 지적 사유가 결함과 맞게 된 것
- **정상 짝 지적**: 바꾸기 전에는 짧은 조건 문장(D-28)을 「지시 대상이 흐린 지시어」로, 바꾼 뒤에는 「설정 파일이 생깁니다」(D-36의 앞 문맥)를 낱말 선택으로 짚음 — 둘 다 새 갈래와 무관함
- **비용**: 바꾸기 전 1.55달러, 바꾼 뒤 1.56달러(API 단가 환산값, 실제 호출은 구독)
- **수치 원본**: 이 폴더의 `before-1.json`, `before-2.json`, `after-1.json`, `after-2.json`
