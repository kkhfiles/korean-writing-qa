# 「~한 것과 ~한 것」 대구 제목과 라벨 실측 (2026-11-26)

**결론** — 관형형 「것」 둘을 대구로 이은 명사구(「덜어낸 것과 남긴 것」)는 사람 업무 문서의 제목과 라벨에 0건(제목 4,835개, 라벨 24,698개), AI 와 작성한 기획 문서에는 제목 24건(21편). 제목은 오류로 올림. 제목 아닌 값에서는 설명용 나열이 섞여(29건 중 12건) 주의로 둠

## 계기

- **사용자 지적** — 발표 덱 장 제목 「재설계 범위 — 덜어낸 것과 남긴 것」을 「전형적인 AI 가 만든 티가 나는 문구」로 짚음(대장 F-331)
- **지적 전 검사기** — 구조 검사기 `doc-style-check.py`(`--relaxed` 와 기본 모두)는 이 제목에 지적 0건. 단어 점검(`rare_words.py`)은 「덜/VV」를 드문 낱말로만 올렸고 대구 꼴은 못 봄

## 반영

- **제목** — 「대구 「것」 제목」(오류). 마크다운 제목과 HTML `<h1>`~`<h6>` 양쪽
- **그 밖의 값** — 「상투 문형」의 「대구 「~한 것과 ~한 것」」(주의). 제목에는 겹쳐 내지 않음
- **본문 문장 안의 대구** — 2층(`core-rules.md` 「「~한 것과 ~한 것」 대구로 이름 대신하지 않기」)
- **같은 덱의 다른 표현** — 「무거운 로직을 덜어낸 경량 실행」은 단어 점검이 「덜/VV」로 올림, 「사람이 쓰는 도구에서 … 실행체로」는 2층 「구체 경로 없는 결산과 결말 공식」의 전환 슬로건. 이 갈래가 아님
