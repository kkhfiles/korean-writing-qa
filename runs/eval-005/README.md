# eval-005 — 전수 판정으로 잰 회수율

**세 문서를 줄 단위로 전부 판정해 얻은 층별 회수율** — 분모가 처음으로 「사람이 알아챈 것」이 아님 · 다만 그 세 문서 안에서만 참

## 결과

| 층 | 회수율 | 잡은 수 |
|---|---|---|
| 1층 · 결정 규칙 + 문서 검사기 | **0.057** | 2 |
| 2층 · 읽기 | **0.771** | 27 |
| 둘 중 하나 | **0.771** | 27 |

**분모 35건** = 나온 지적 중 사용자가 동의한 29건 + 아무도 못 잡은 6건
**분모에서 뺀 것** — 오탐 1 · 보류 1

## 앞 수치와 무엇이 다른가

| | eval-003 | eval-005 |
|---|---|---|
| 분모 | 사람·모델이 읽다가 알아챈 것 13건 | 판정 대상 줄 전수 |
| 값 | 0.846 | 0.771 |
| 쓸 수 있나 | **못 씀** — 같은 종류 읽기가 만든 라벨 | 씀 · 세 문서 한정 |

**둘을 나란히 비교하지 말 것** — 재는 대상이 다르다.

## 1층 0.057 읽는 법

**놀랄 값이 아님** — `runs/diagnostic-006`이 이미 낸 결론을 숫자로 확인한 것이다. 1층 규칙은 사용자가 확정한 교정을 **원문 그대로 문자열 대조**한다. 좁히면 다시 안 걸리고 넓히면 정상 문장을 잡는다.

**잡은 2건은 전부 전역 문서 검사기가 낸 것** — 스킬의 결정 규칙은 이 세 문서에서 0건이다.

## 아무도 못 잡은 6건

| 문서:행 | 구절 | 사용자 지적 |
|---|---|---|
| doc-002:22 | 로컬 실행 환경 구축 기능 추가 | 조사가 하나도 없음 |
| doc-004:18 | 에러 | 「오류」로 바꿀 것 |
| doc-004:51 | 인도 | 다른 낱말 필요 |
| doc-004:52 | 재정립 | 뜻이 모호함 |
| doc-004:58 | AI 조립 라인 | 용어·브랜드면 원문 병기 |
| doc-004:63 | 시드 | 무슨 뜻인지 안 통함 |

**doc-004에 다섯이 몰림** — 2층이 그 문서에서 특히 덜 잡았다. 표본이 셋뿐이라 문서별 편차인지 갈래별 약점인지는 판정 불가.

## 오탐 1건 · 보류 1건

| 판정 | 구절 | 사용자 말 |
|---|---|---|
| 오탐 | 에이전틱 → 자율 수행 | 「에이전틱은 용어다. 고치면 안됨」 |
| 보류 | 포지셔닝 → 제품 설명 | 「정확히 대응되는 표현이 아닌데 어떤 맥락인지 확인 필요」 |

**둘 다 이미 규칙에 적혀 있는 것** — 「불필요한 영어 줄이기」의 예외 두 갈래(업계에 굳은 외래어 · 뜻이 같은 대체어가 없는 말)가 8월 27일에 들어갔고, 이 측정은 **8월 26일 실행분**이라 그 규칙 이전이다.

**그래도 빈 곳이 남음** — 판단 층이 읽는 회귀 시료 13건이 **전부 「고쳐라」**이고 「고치지 말라」가 0건이다. 규칙 문장만 있고 반대 예가 없다.
