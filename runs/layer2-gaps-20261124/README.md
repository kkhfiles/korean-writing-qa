# 외부 검토가 잡고 2층이 놓친 갈래 반영 전후 측정

**블로그 원고의 외부 모델 최종 검토가 짚고 2층 판정기가 놓친 문맥 갈래 둘을 9단계에 넣을지** — 판정 기준은 결과 확인 전에 작성(측정 결과 위치: 「결과」 절)

## 출처와 바꾸는 규칙

- **출처**: 블로그 원고 검토 인계(2026-11-24) — 외부 모델 최종 검토가 짚고 사용자가 받아들인 지적 가운데 판정기가 놓친 것
- **새로 넣는 갈래**: 「비교 대상의 범주가 어긋남」(결과물과 사람을 견줌), 「비유가 가리키는 대상이 바뀜」(앞 문장의 비유를 뒤 문장이 다른 대상으로 받음)
- **넣지 않는 것**: 근거 범위(인용 원문이 말하지 않은 것을 단정) — 판정기가 인용 원문을 받지 않아 문서만으로 못 가름. 출처 메모를 함께 넘기는 선택지는 따로 검토
- **이미 있는 갈래**: 지시 대상(「그 비용」) — 「지시 대상이 흐린 지시어와 재귀 표현」에 시료 한 짝만 더함(규칙 변경 없음)
- **반영 위치**: `finalize-korean-document` 9단계 항목

## 측정 방법

- **비교 대상**: 바꾸기 전 규칙(측정 직전 커밋)과 바꾼 뒤 규칙(작업 트리)
- **탐침**: `scripts/probe_layer2_discourse.py` — 판정기와 같은 프롬프트, Opus, 구독 호출
- **운반 문서 1**: `tests/fixtures/layer2-discourse/cases.jsonl` — 기존 사례 38건(D-01~D-38)과 새 사례 10건(D-39~D-48)
- **운반 문서 2**: `tests/fixtures/layer2-kinds/carrier.md` — 대장 2층 몫과 예비 예문
- **반복**: 운반 문서 1은 규칙마다 2회, 운반 문서 2는 규칙마다 1회
- **새 사례의 성격**: 원고 문장이 아니라 같은 꼴로 새로 지은 문장

## 사전 판정 기준

**판정** — 아래 다섯 기준을 모두 넘으면 「반영」, 하나라도 미달이면 「보류」(합계는 운반 문서 1의 두 회를 더한 값)

| 기준 | 지표 | 넘는 조건 |
|---|---|---|
| 새 사례 회수 비악화 | 새 갈래 결함 사례 줄 회수(D-39, D-41, D-43, D-45, 두 회 합계 8번 중) | 바꾼 뒤가 바꾸기 전 이상 |
| 새 정상 짝 보존 | 새 갈래 정상 짝 줄(D-40, D-42, D-44, D-46)에 새 갈래 이름으로 낸 지적 | 바꾼 뒤 1건 이하 |
| 정상 짝 전체 보존 | 정상 짝 전체에 낸 지적 줄 수 | 바꾼 뒤가 바꾸기 전보다 2 이하로 많음 |
| 기존 사례 회수 비악화 | D-01~D-38 결함 사례 줄 회수 | 바꾼 뒤가 바꾸기 전보다 2 이하로 적음 |

- **회수 증가는 반영 조건이 아님** — 외부 규칙은 넣는 것이 기본이라(`AGENTS.md` 「판단이 갈릴 때」), 해치지 않으면 넣음
- **참고로만 적는 것**: D-47(기존 지시 대상 갈래) 회수
- **재판정 변동**: 같은 입력 재판정 시 지적 수 평균 16% 변동(2026-09-30 실측)
- **회차 한계**: 두 회차로는 작은 차이 판정 불가
