# AI 말투 시연 (2026-11-11)

**결론** — AI 말투 51개를 일부러 넣은 가상 주간보고를 실사용 흐름으로 고치니 36개가 없어지고 15개가 남음. 규칙 검사 오류는 6건에서 0건. 고치는 과정에서 작성자에게 맡길 지시문이 본문에 남고 확실성이 바뀐 곳이 생김. 측정이 아니라 시연이고 같은 입력도 실행마다 결과가 다름(측정 결과는 [value-ai-docs-20261109](../value-ai-docs-20261109/README.md), [bench-external-20261031](../bench-external-20261031/README.md))

## 만든 까닭

- **사용자 제안(2026-11-11)** — 「가장 효과를 직접적으로 느낄 수 있는건 못쓴 글과 고쳐진 글을 바로 볼 수 있을때이다」, 「모든 AI말투를 넣어서 업무 보고서를 하나 만든다음에 그걸 고친걸로 비교하면 극명하게 보일 듯」
- **화면** — 원문과 고친 글을 줄마다 나란히 놓고 빠진 글자와 새로 들어간 글자를 색으로 표시(전후 비교 페이지 생성기 `showcase.py` 의 비교표를 그대로 씀)

## 입력

- **원문** — 테스트자동화팀의 가상 주간보고. 측정에서 모델들이 실제로 쓴 주간보고의 모양(굵은 항목 머리와 하위 목록, 「~완료.」 종결, 총평 문단)을 따르고, 낱말과 문형에 검사기 규칙, 2층 판단 규칙, im-not-ai 분류표의 AI 말투를 넣음(측정용 표본이 아님)
- **일부러 넣은 말투 목록** — 말투마다 원문 구절, 갈래, 남았는지 가를 표지 정규식(예: 「시점이며」는 「시점」)
- **고친 흐름** — `value-ai-docs-20261109/run.py` 의 실사용 흐름(checker2) 그대로. 2층 판정과 수정안 반영, 1층 오류 줄 고침, 고친 줄 재판정. 문서 형식은 개조식으로 지정, 사람의 개입 없음

## 결과

| 항목 | 값 |
|---|---|
| 일부러 넣은 말투 | 51개 |
| 고친 글에서 없어진 말투 | 36개 |
| 남은 말투 | 15개 |
| 규칙 검사 오류 | 6건 → 0건 |
| 판정기 수정안 반영 | 45건 |

- **남은 말투** — 이모지 제목, 영어 병기 「(Issues & Risks)」, 「단순한 X를 넘어」, 「매우 의미 있는 한 주」, 「향후 … 발판」, 「올바른 결과」, 「즉,」, 「상당히 … 것으로 판단됨」, 「~로 인한」, 「경로」와 「갈래」, 작업 흔적 「(작업 노트 #12 참고)」, 「미완료」, 「재정립」, 「A가 아니라 B」
- **남았는지 가르는 방식의 한계** — 표지 글자가 있는지만 봄. 없어졌어도 잘 고쳤는지는 비교표를 읽어야 갈림

## 고치며 생긴 문제

- **작성자에게 맡길 일이 본문에 남음** — 총평에 「(구체적으로 무엇이 바뀌었는지 기재)」가 들어감
- **확실성 변경** — 「감소한 것으로 보임」이 「감소함」으로 바뀜
- **뜻을 좁힘** — 「리소스를 효율적으로 얼라인」이 「단계별 인력 배정」으로 바뀜
- **원문에 없던 줄** — 총평에 다음 주 계획 요약 줄이 들어감

## 앞선 두 실행(같은 날, 결과는 작업 폴더에 보관)

- **첫 실행 — 문단으로 쓴 원문** — 원문이 「~습니다」 문단이라 비교표 대부분이 종결 바꾸기로 채워짐. 사용자 「before가 서술형인건 너무 억지스러운데」로 원문을 실제 AI 보고서 모양으로 다시 씀. 60개 중 39개 없어짐
- **둘째 실행 — 다시 쓴 원문** — 51개 중 37개 없어짐. 그러나 원문의 「(진위 미확인)」 표시를 발행 게이트가 막아(확인 안 된 내용 표시는 원본 줄이어도 막음) 같은 갈래의 작업 흔적 「(작업 노트 #12 참고)」로 바꾸고 다시 실행
- **두 실행에서만 난 문제** — 「↵ 하위 항목 「…」」나 「↵」가 글자 그대로 들어감(판정기가 「하위 항목으로 나눔」을 표기로 낸 수정안을 반영 단계 `bench_loop.process` 가 글자 그대로 넣음, 표기는 대표 수정 표 `core-rules.md` 의 한 행에서 옴), 판정기가 대표 수정 표의 「도구가 아니라 방식이라 가져갈 수 있습니다」 행을 적용 조건 밖에서 옮겨 「다른 프로젝트에도 적용할 수 있음」이라는 원문에 없던 주장을 넣음, 「1판」을 「1.0 버전」으로 바꿈

## 함께 고친 게이트 결함

- **증상** — 첫 실행 페이지를 발행하려 하자 원본(`origin.txt`)으로 선언한 시연 원문 줄의 오류 4건이 발행을 막음
- **원인** — 한 표 칸에 원본 줄이 이어 있으면 검사기가 찍는 문맥이 두 줄에 걸쳐 어느 원본 줄에도 통째로 들지 않았고, 지적이 짚은 표현 뒤에 안내와 문맥을 잇는 꼴이면 문맥을 떼어 보지 않았음
- **고침** — `hooks/doc-style-gate.py` 의 `drop_theirs` 가 원본 줄을 차례대로 이은 글과도 견주고, 두 꼴에서 문맥만 떼어 견줌. 시험은 `tests/test_origin_lines_are_theirs.py` 의 두 줄에 걸친 문맥 시험
