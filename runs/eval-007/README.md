# eval-007 — 규칙에 적은 예외가 판단 층의 행동을 바꾸는가

**호출 1회로 확인 · 둘 다 통과** — 예외 지킴 · 확정 교정 재현 · 비용 0.304달러(추정의 10배)

## 물은 것

**「규칙을 썼다 ≠ 규칙이 적용된다」의 마지막 미확인 지점** — 1층은 시험으로 막았지만 판단 층에는 그 확인이 없었다.

**시료** — 「에이전틱」. 2층이 고치라고 냈고, 사용자가 아니라 했고, 2026-08-27에 `core-rules.md`의 「뜻이 같은 대체어가 없는 말」 예외에 이름이 올랐다. **그 뒤로 판단 층을 한 번도 안 돌려 봤다.**

## 확인된 것 둘

**① 되먹임이 규칙에서 행동까지 닿음** — 사용자 판정 → 규칙 문서의 예외 → 판단 층의 행동 변화가 실제로 이어진다.

**② 확정 교정 표가 읽히고 적용됨** — 22행이 사용자가 확정한 문구와 글자까지 같다. 「사용자가 확정한 대표 수정」 표가 유일한 통로인데, 그 통로가 실제로 뚫려 있다.

## ⚠️ 비용 추정이 10배 틀림

**0.03달러로 잡았는데 0.304달러**

| 항목 | 토큰 | 비용 |
|---|---|---|
| 출력 | **12,229** | 0.183 |
| 캐시 생성 | 30,163 | 0.113 |
| 캐시 읽기 | 25,603 | 0.008 |

**틀린 지점** — 낸 것이 JSON 5줄이라 출력 1천 토큰으로 잡았다. **생각(thinking)이 출력에 포함된다.** 캐시 생성 30K는 Claude Code 자체 시스템 프롬프트이고, 클라이언트가 이미 `tools=[]`·`max_turns=1`이라 더 깎을 데가 없다.

**깎을 수 있는 유일한 길** — 연속 실행. 캐시가 살아 있는 동안 몰아 돌리면 회당 0.11달러가 준다.

## 여기서 멈춘 이유

**물은 것에 답이 나옴** — 하네스를 지으려던 까닭이 이 물음이었고, 호출 1회가 답했다.

**안 한 것** — 전수 판정 문서 3건으로 2층 회수율 0.771을 재현하는 1단계(0.68달러). 알아 두면 좋지만 지금 무엇을 바꾸지 않는다.
