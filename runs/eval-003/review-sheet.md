# 2층 지적 판정 요청 — eval-003

**2층 검사가 새로 낸 지적 20건 · 정오 판정 요청** — 판정 칸에 「맞음」·「오탐」·「보류」 중 하나만 남기고 나머지 삭제 · 기존 라벨과 겹치는 12건은 대상 아님

## 왜 이 판정이 필요한가

**이 20건이 순환하지 않는 유일한 값** — 기존 라벨 13건은 전부 읽기 통과에서 나와서, 같은 종류의 통과로 다시 찾은 회수율 0.846은 성적으로 못 쓴다. 반면 새 지적의 정오는 사람 판정이 정하므로 순환이 없다.

**정밀도가 회수율보다 중요** — 이 프로젝트 기준이 「정상 문장을 지적하지 않는 정확도 우선」이다. 여기서 나오는 값이 곧 2층 정밀도다.
