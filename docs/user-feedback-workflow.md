# 사용자 문체 피드백 반영

**사용자 수정 기록을 후보로 보존하고, 근거와 회귀시험을 갖춘 표현만 실제 검사 규칙에 반영**

## 저장 대상

| 자료 | 위치 | 역할 |
|---|---|---|
| 피드백 후보 | `data/feedback/candidates.jsonl` | 사용자 수정·수락·거짓양성·모델 관찰 기록 |
| 후보 스키마 | `data/feedback/candidate-schema.json` | 필수 필드와 허용값 정의 |
| 활성 표현 규칙 | `data/annotations/user-confirmed-phrases.jsonl` | QA 검사기가 읽는 확정 표현 · 스킬의 실행 사본과 동일하게 유지 |
| 일반 문체 원칙 | `data/annotations/user-style-preferences.jsonl` | 여러 수정에서 확인한 공통 기준 |

**후보 파일 생성**: 첫 기록 시점

**검사 결과 반영**: 후보 저장만으로는 변경 없음

## 처리 순서

1. **후보 수집**: 수정 전후 표현과 판단 근거 기록
2. **문맥 범위 결정**: 문장·앞뒤 문장·구조 묶음·문서 전체 중 실제 판단에 필요한 범위 선택
3. **사람 판단 확인**: 사용자 직접 수정·사용자 수락·사람 검토 여부 확인
4. **승격 미리보기**: 새 규칙과 양성·권장·설명·범위 밖 시료 확인
5. **회귀시험 후 활성화**: 탐지·의미 보존·피드백 처리 시험 통과
6. **실문서 확인**: 새 규칙이 적용되는 문서 종류에서 거짓양성 점검

**문서 종류 격리**: `--profile`로 수집한 규칙은 해당 문서 종류에서만 검사 · 승격할 때 다른 문서 종류의 음성 시료 자동 생성

## 문맥 저장 범위

| 범위 | 선택 기준 | 함께 저장할 값 |
|---|---|---|
| `sentence` | 짧은 문구나 독립 문장만으로 판정 가능 | 수정 전후 표현 |
| `window` | 지시 대상·인과·진행 상태 확인 필요 | 필요한 앞문장 또는 뒷문장 |
| `block` | 표·목록·슬라이드 구조가 판단을 좌우 | 절 제목·논리 위치·판단에 쓴 구조 한 줄 |
| `document` | 문서 전체 상태·용어 정의 확인 필요 | 원본 참조와 해시 · 문서 사본은 기본적으로 저장하지 않음 |

**문맥 저장 원칙**: 판단에 실제로 쓴 범위만 저장 · 쓰지 않은 주변 문장 제외

## 판단 근거와 자동 반영

| 판단 근거 | 후보 상태 | 실제 규칙 승격 |
|---|---|---|
| 사용자가 직접 고침 | `confirmed` | 가능 |
| 사용자가 제안을 받아들임 | `confirmed` | 가능 |
| 사람이 별도로 검토함 | `confirmed` | 가능 |
| 모델이 후보만 찾음 | `observed` | 불가 |
| 사용자가 거짓양성으로 판정함 | `confirmed` | 양성 규칙으로 승격 불가 · 예외 시료로 별도 처리 |

**언어 정책 승격**: 사람 판단 필수

**기술 변경**: 별도 사용자 승인 불필요 · 형식 지원·실행 오류 처리·검사기 결함 수정 전에 실패 재현 시험 추가

## 실행

**후보 수집 시작**: 미리보기

**QA 저장소 기본 위치**: `P:/github/korean-writing-qa` · 다른 복사본은 `KOREAN_WRITING_QA_HOME`으로 지정

```powershell
python C:/Users/<사용자>/.claude/skills/finalize-korean-document/scripts/record_feedback.py `
  --candidate-id <고유-ID> `
  --rule-id <규칙-ID> `
  --original <수정-전> `
  --revised <수정-후> `
  --profile <문서-종류> `
  --decision-source user_direct `
  --user-verdict corrected `
  --context-level sentence
```

**후보 기록**: 내용 확인 후 `--apply`

**규칙 반영 시작**: 승격 미리보기

```powershell
python C:/Users/<사용자>/.claude/skills/finalize-korean-document/scripts/promote_feedback.py `
  --candidate-id <고유-ID>
```

**규칙 반영**: `--apply` · 스킬과 QA 저장소의 활성 규칙·회귀 시료 동시 갱신 · 자체 시험 실행

**중단 조건**: 작업 전 두 사본 불일치

**시험 실패**: 후보·규칙·시료·개수 명세를 적용 전 상태로 복원
