# 규칙 후보

**실문서 진단 전 자동 규칙으로 승격하지 않은 표현** — 사용자 관찰·초기 가설·반례·측정 결과 관리

## 추상적 `경로`

- **후보 ID**: `KOR-METAPHOR-PATH-001`
- **상태**: 진단 중 · 자동 경고 금지
- **분류**: `UNNATURAL_METAPHOR`
- **가설**: 사람은 IT 업무에서 `경로`를 실제 path 의미로 주로 사용 · 목표나 진행을 나타내는 추상 명사와 결합하면 번역투 가능성 큼
- **양성 예**: `제품화 경로` · `해결 경로` · `복구 경로`
- **정상 예**: `파일 경로` · `절대 경로` · `UNC 경로` · 메뉴 이동 경로

### 초기 진단

- **진단 방법**: 보고서 587개의 모든 `경로` 용례 추출 · 실제 path 후보와 추상 명사 결합 후보 분리 · 나머지는 사람 판정
- **초기 측정**: 241개 문서 · 771회 등장 · 추상 명사 결합 8건 · 실제 path 후보 132건 · 사람 검토 631건
- **승격 조건**: 사람이 판정한 실문서 표본에서 낮은 오탐 확인 · 탐지하지 않은 정상 용례 회귀시험 확보

**판정 단위** — 단어 자체를 바꾸는 규칙이 아니라 `경로`가 무엇을 가리키는지 판정하는 규칙이다. `호출 경로`·`실행 경로`처럼 IT에서 쓰이지만 실제 파일 path가 아닌 표현은 초기에는 사람 검토 대상으로 남긴다.
