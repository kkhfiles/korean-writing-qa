## 추상적 `경로`

- **후보 ID**: `KOR-METAPHOR-PATH-001`
- **상태**: `제품화 경로` 확정 · 그 밖의 결합은 진단 중
- **분류**: `UNNATURAL_METAPHOR`
- **가설**: 사람은 IT 업무에서 `경로`를 실제 path 의미로 주로 사용 · 목표나 진행을 나타내는 추상 명사와 결합하면 번역투 가능성 큼
- **확정 치환**: `제품화 경로` → `제품화 단계`
- **추가 후보**: `해결 경로` · `복구 경로`
- **정상 예**: `파일 경로` · `절대 경로` · `UNC 경로` · 메뉴 이동 경로 · 호출 경로 · 실행 경로

### 초기 진단

- **진단 방법**: 보고서 587개의 모든 `경로` 용례 추출 · 실제 path 후보와 추상 명사 결합 후보 분리 · 나머지는 사람 판정
- **초기 측정**: 241개 문서 · 771회 등장 · 추상 명사 결합 8건 · 실제 path 후보 132건 · 사람 검토 631건
- **승격 조건**: 사람이 판정한 실문서 표본에서 낮은 오탐 확인 · 탐지하지 않은 정상 용례 회귀시험 확보

### 확인된 AI 보고서 표본

- **표본 측정**: 20개 문서 가운데 11개에서 33회
- **자동 분류**: 실제 path 후보 14건 · 사람 검토 19건 · 추상 비유 후보 0건
- **사람 판정**: 33건 모두 파일·원격 저장소·권한 설정·명령 실행의 실제 path 문맥
- **추가 용도**: 정상 용례 회귀시험 · 추상 비유 적중률은 양성 사례 확보 뒤 판정

### 다중 형식 표본

- **표본 측정**: 149개 원본 단위 가운데 28개에서 68회
- **최종 분류**: 실제 path 후보 59건 · 사람 검토 8건 · 추상 비유 후보 1건
- **사람 검토 조건**: 실제 path로 단정할 수 있는 앞뒤 단서 부족
- **정상 용례 보완**: Windows·import·권한·원격·소스·보고서·네트워크 공유의 실제 위치와 호출 흐름
- **추상 비유 후보**: `에이전트가 … 경로를 이탈` · 사람 판정 전 자동 수정 금지

**판정 단위** — 단어 자체가 아니라 `경로`가 무엇을 가리키는지 판정한다. `호출 경로`·`실행 경로`처럼 IT에서 흐름을 뜻하는 용례도 실제 path로 분류한다.

**외부 도구 대조** — `korean-report-skills`의 권장 예시에는 `장비 매칭 검증 경로 복구`가 있다. 외부 규칙도 `경로`의 추상적 사용을 허용하므로 이 저장소의 사용자 확정 기준을 우선한다.

## 명사에 붙인 서술격조사를 동사처럼 활용

- **후보 ID**: `KOR-COPULA-CONJ-001`
- **상태**: 사례 등록 완료 · **규칙 미작성** · 회귀 시료 `C-005`~`C-022`
- **분류**: `INVENTED_INFLECTION`
- **증상**: 「문제다」를 존댓말로 옮기며 동사 어간처럼 활용 → 「문젭니다」 · 바른 형태는 「문제입니다」
- **기존 검사를 통과하는 이유**: 문법상 존댓말 형태라 「반말 서술형」·「서술형 종결」 어디에도 미해당 · 값 슬롯 밖 산문이면 지적 0
- **발견 경위**: 반말→존댓말 **기계 변환** 산물 · 발행 직전 자료 다섯에서 13곳 · 문체·정합성 검사 모두 통과 · 어형 215종을 사람이 훑어서 발견(2026-09-09)
- **성격**: 사람이 쓴 한국어에 없는 형태 · 손으로 쓸 때는 안 나옴

### 잡아야 할 것 — `C-005`~`C-016`

| 나온 형태 | 바른 형태 |
|---|---|
| 「문젭니다」·「자립니다」·「별갭니다」·「의돕니다」 | 「문제입니다」·「자리입니다」·「별개입니다」·「의도입니다」 |
| 「일붑니다」·「재룝니다」·「하납니다」·「페이집니다」 | 「일부입니다」·「재료입니다」·「하나입니다」·「페이지입니다」 |
| 「전젭니다」·「형탭니다」·「장칩니다」·「영업니다」 | 「전제입니다」·「형태입니다」·「장치입니다」·「영어입니다」 |

### ★ 비슷하게 생겼지만 잡으면 안 되는 것 — `C-017`~`C-022`

**규칙을 넓히면 먼저 깨지는 곳** · 둘 다 실제로 겪은 충돌

| 충돌 갈래 | 정상 표현 | 겹치는 명사 |
|---|---|---|
| **명사 = 동사 어간** | 「가집니다」(가지다)·「여깁니다」(여기다)·「고칩니다」(고치다)·「마칩니다」(마치다) | 가지·여기·고치·마치 |
| **끝 음절이 「이」** | 「차입니다」(차 + 입니다)·「사입니다」(사입) | 차이·사이 |

### 탐지법 — 실측 결과 둘

- **자동 수집 방식 기각** — 「N입니다」·「N이다」에서 명사를 모아 금지어를 만드는 방식. 한 프로젝트에서 「가지」가 명사로 13곳 쓰여 금지어 「가집니다」가 생성되고, 그것은 「가지다」의 정상 활용형이다(같은 문서 셋에 3곳 실재). **오탐이 구조적** · 재현율도 12종 중 8종
- **고정 목록 방식 채택 권고** — 각 항목의 동사 읽힘 여부를 확인하고 넣으면 **오탐 0 · 위 12종 전부 탐지** · 자동 수집보다 안전하면서 재현율도 높음
- **제외 규칙 둘**: ①동사 어간과 겹치는 명사 ②**끝 음절이 「이」인 명사 전부**

### 승격 조건

- **작성 방식**: 고정 목록 · `[낱말]` 갈래 · 기존 「지어낸 명사구」의 자매 규칙
- **등급 제안**: 오류 — 오탐 0이 설계로 보장 · 사람이 쓴 한국어에 없는 형태
- **반영 뒤 확인**: `python scripts/add_case.py --recheck` → `C-005`~`C-016`이 `pinned` 로 올라가고 `C-017`~`C-022`가 `pinned` 유지

### 남은 판단 — 규칙 작성 여부

- **찬성 근거**: 기존 검사 어디에도 안 걸린 채 **발행본에 닿음** · 비용은 목록 하나와 대조 한 번
- **반대 근거**: 발생 1회 · 근본 원인은 글이 아니라 **변환 스크립트** · 이 저장소 원칙은 「오탐이 미탐보다 비쌈」
- **지금 상태**: 사례를 박아 두어 **규칙 없이도 회귀 시험이 이 갈래를 기억함**
