# 검사 항목과 목적

**검사 항목 전체와 각 항목의 목적** — 「누구에게나 맞는 규칙」과 「한 사람의 취향」을 가르는 여러 AI 상호 검토용 목록(할 일과 답하는 형식: 맨 아래 「검토 요청」)

## 이 검사기가 하는 일

**목적** — AI가 도와 쓴 한국어 업무 문서에서 읽는 사람이 걸리는 표현을 발행 전에 찾습니다. 사람이 쓴 글에는 드문데 AI가 쓴 글에 자주 나오는 표현, 뜻이 흐리거나 잘못 읽히는 표현이 대상입니다.

**층 구분**

| 층 | 방식 | 맡는 것 |
|---|---|---|
| 1층 | 정규식과 형태소 분석으로 줄마다 검사 | 글자 모양만으로 가릴 수 있는 것 |
| 단어 점검 | 사람이 쓴 업무 한국어 4,790만 자 기준선과 낱말 빈도 비교 | 기준선에 드문 낱말(판정하지 않고 볼 곳만 좁힘) |
| 2층 | AI 판정기가 규칙 문서를 읽고 문서 전체를 판단 | 문맥을 봐야 갈리는 것 |

**등급** — 「오류」는 발행을 막고, 「주의」는 사람이 보고 판단합니다.

**항목마다 적은 것**

- **잡는 것과 예** — 예문은 「」 안에 표기
- **목적** — 그 표현이 왜 문제인지
- **계기** — 처음 생긴 계기(사용자 지적, 실측, 문법서)
- **근거** — 그 뒤에 측정한 값이나 사례
- **사람 글** — 기준선 말뭉치나 회사 문서 색인처럼 사람이 쓴 글 묶음

## 검토 요청

**할 일** — 위 항목마다 아래 셋 중 하나를 고르고 까닭을 한 줄로 적습니다.

| 분류 | 뜻 | 이 검사기를 받아 쓰는 다른 사람의 기본값 |
|---|---|---|
| 공통 | 누구의 업무 문서에서든 읽는 사람이 걸리는 표현 | 켜짐 |
| 형식 | 조직마다 다를 수 있는 문서 형식 약속 | 켜짐, 조직이 끌 수 있음 |
| 개인 | 한 사람의 취향이나 특정 문서에만 맞는 수정 | 꺼짐, 각자 자기 것으로 교체 |

**가를 때 볼 것**

- **계기가 사용자 지적이라는 것만으로 개인이 되지 않음** — 거의 모든 항목이 사용자 지적에서 시작했습니다. 사람 글 실측, 오독 사례처럼 그 뒤에 쌓인 근거를 봅니다.
- **사람 글에서 정당한 쓰임이 0건인 짝** — 다른 사람에게 켜 두어도 오탐이 거의 없습니다. 공통으로 두는 비용이 낮다는 점을 함께 고려합니다.
- **확신이 없으면** — 확신 「낮음」으로 적고 갈리는 까닭을 적습니다. 억지로 고르지 않습니다.

**답하는 형식** — 번호 순서대로 한 줄씩

```
번호 | 분류 | 확신(높음/중간/낮음) | 까닭
L1-01 | 형식 | 높음 | 개조식을 쓰지 않는 조직에는 맞지 않음
```

**다른 검토자의 답을 받았을 때** — 자기 답과 다른 항목만 골라, 상대 까닭이 맞으면 자기 답을 바꾸고 아니면 반론을 한 줄로 적습니다. 바꾼 항목과 유지한 항목을 나눠 적습니다.
