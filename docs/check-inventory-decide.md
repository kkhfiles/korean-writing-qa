## 까닭

### L1-08

- **Fable(개인)** — 「넣을 자리」처럼 위치 뜻의 「자리」는 사전 표준 용법이고, 5.3배 근거의 비교 기준이 사용자 본인 글이어서 한 사람의 선호가 섞임
- **Argon(공통)** — AI가 사람보다 5.3배 많이 쓰는 전형적 AI 상투어로 단계나 시점의 뜻을 흐림
- **Claude(공통)** — 지점을 「자리」로 부르면 문장인지 단계인지가 사라짐, AI 글에 몰림

### L1-12

- **Fable(형식)** — 외부 공유 문서에서는 「우리」가 모호하지만 사내 문서의 「우리 팀」은 정상이라 오류 등급은 공유 범위를 정하는 조직 약속
- **Argon(공통)** — 「우리」나 「이들」처럼 가리키는 대상이 모호한 대명사는 업무 문서에서 오해를 부름
- **Claude(공통)** — 공유 문서에서 소속에 따라 뜻이 갈림

### L1-19

- **Fable(공통)** — 가운뎃점은 붙여 쓰는 것이 표기 규정이고 「A와 B 모두」 오독이 실제 재발했음, 다만 「새로 쓰거나 고친 줄만」 조건은 운영 규칙
- **Argon(형식)** — 오독 사례가 있어 주의가 필요하나 가운뎃점 띄어쓰기 자체를 오류로 막는 것은 조직 표기 규칙임
- **Claude(공통)** — 실제 오독 재발

### L1-28

- **Fable(형식)** — 절 번호 참조는 규격·법령 문서의 표준 관행이고 절이 바뀌는 문서에서만 문제라 조직 약속
- **Argon(형식)** — 절 번호 참조(「§3」, 「5-1절」)는 법률·규격·공문서에서 널리 쓰이므로 이를 막는 것은 조직의 문서 관리 약속임
- **Claude(공통)** — 절이 바뀌면 엉뚱한 절을 가리킴(실제 사례), 남의 문서 조항은 이미 예외

### L1-30

- **Fable(형식)** — 문체 규칙이 아니라 검사기 운영 알림이어서 세 분류 어디에도 딱 맞지 않음, 켜 둬도 해가 없어 형식으로 둠
- **Argon(형식)** — 문서 형식 메타데이터 표기와 코드 블록 내 한글 검사는 이 검사기 워크플로에 맞춘 규칙임
- **Claude(공통)** — 검사 범위 안내라 켜 둬도 해가 없음

### P-18

- **Fable(형식)** — 「프로세스가 죽다」는 개발 조직 내부 문서에서 관용어이고 외부 문서에서는 입말이라 조직이 정할 일, 사내 쓰임 1건이 그 갈림을 보여 줌
- **Argon(공통)** — 공식 문서에서는 「종료」, 「중단」이 적절하나 IT 실무 문서에서는 「세션이 죽다」처럼 쓰이기도 함
- **Claude(공통)** — 주의 등급

### P-20

- **Fable(개인)** — 「매일 밤」은 표준 표현이고 동료의 정당 쓰임 있음, 시각을 정확히 쓰라는 뜻이면 「밤」 자체 금지가 아니라 시각 누락을 봐야 함
- **Argon(공통)** — 요구사항이나 기술 문서에서 「매일 밤」은 시각이 모호하므로 「자정」, 「야간」으로 명확히 적어야 함
- **Claude(개인)** — 동료의 정당한 쓰임

### P-21

- **Fable(공통)** — 「제품을 내다」는 표준어이나 업무 보고서에서 「출시」가 맞다는 것은 널리 통함, 색인 74곳이 대화 말투라는 근거 있음
- **Argon(공통)** — 출시·발표·제출을 「냈다」로 뭉뚱그리는 것은 구어체라 공식 업무 문서에 맞지 않음
- **Claude(개인)** — 사용자 판단, 색인 74곳

### P-22

- **Fable(형식)** — 업무 글에서는 「수정」이 맞지만 「자동 프로그램 수리」는 SE 학계에서 정착된 번역어라 연구 조직은 끌 수 있어야 함
- **Argon(공통)** — 소프트웨어 결함이나 취약점에는 「수리」가 아니라 「수정」이나 「패치」가 표준 IT 용어임
- **Claude(개인)** — 학계 번역어

### P-23

- **Fable(개인)** — 「초판·2판」처럼 「판」은 출판·소프트웨어에서 버전 뜻의 표준어이고 회사 색인 57곳 쓰임, 「거의 사용하지 않음」은 사용자 체감
- **Argon(공통)** — IT·일반 업무에서는 「버전」, 「차수」가 자연스러우나 출판·인쇄 도메인에서는 「판」이 정당한 용어임
- **Claude(개인)** — 색인 57곳

### P-24

- **Fable(공통)** — 화면 배치를 「세우다」로 쓰는 것은 비유라 뜻이 흐림, 근거가 사내 0~2건으로 적음
- **Argon(공통)** — UI 동작을 「앞에 세우다」로 적는 것은 의미가 모호한 AI식 비유임
- **Claude(개인)** — 근거가 사용자 지적뿐

### P-26

- **Argon(공통)** — 「아무 데도」는 구어체에 가까워 문어체 업무 문서에서는 「어디에도」가 자연스러움
- **Claude(개인)** — 표준어

### P-27

- **Fable(공통)** — 입말 비유라 뜻이 흐림, 다만 근거가 없고 주의 등급

- **Claude(형식)** — 의문형 제목은 제목 양식
