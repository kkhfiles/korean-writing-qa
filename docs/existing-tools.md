## `humanize-korean` 2.3.2 재검토 (2026-10-23)

- **계기**: 언론 보도(AI타임스 2026-10-22)
- **설치본**: 이 PC에서 1.5.0을 2.3.2로 올림
- **저장소**: `epoko77-ai/im-not-ai`(MIT 라이선스)
- **가져온 방식**: 코드는 옮기지 않고 측정 방법과 판정 선만 빌림
- **새로 생긴 것**: 패턴 70여 개, 사람 글과 AI 글 각 60편의 로그우도비 판별력 실측, 변경률 게이트, 문장 단위 서법 복원
- **장르 차이**: im-not-ai 실측 대상은 칼럼과 에세이, 논설이라 업무 문서에 맞는지 다시 재야 함

**업무 문서로 다시 측정한 결과** — 사람 업무 문서(노션, 제품 문서, 사내 규정 중 2023년까지 고친 것 1,664편, 한글 36만 자)와 AI 업무 문서(진단 표본과 실험 산출물 254편, 한글 35만 자)를 같은 정규식으로 셈. 단위는 한글 1만 자당 건수.

| 패턴 | 사람 | AI | 판정 |
|---|---|---|---|
| 「A가 아니라 B」 대구 | 0.33 | 3.39 | **검사기 주의로 반영(한 문서에 몰린 경우)** |
| 「~되고 있다」 피동 진행 | 1.47 | 0.40 | 미반영 — 사람이 더 많이 씀 |
| 연결어미 뒤 쉼표 | 12.08 | 8.76 | 미반영 — 업무 문서에서는 사람이 더 많이 씀 |
| 범용 정책동사(확대, 강화, 구축 등) | 4.55 | 3.73 | 미반영 — 차이 없음 |
| 「~것이다」 종결 | 0.87 | 0.85 | 미반영 — 차이 없음(im-not-ai 실측도 사람이 더 많이 써서 뺌) |

**반영한 것**

- **검사기 「「~가 아니라」 반복」(주의)**: 한 문서에 두 번 이상이면서 한글 1만 자당 3회 이상일 때 지적하고 지시 파일은 뺌. 300자 넘는 문서 중 두 번 이상 쓴 비율이 사람 284편 중 1편, AI 238편 중 17편이었음
- **`check_meaning.py` 의 `meaning_marker_sentences`**: im-not-ai 서법 복원 도구처럼 문장을 짝지어 표지가 바뀐 문장을 짚음. 되돌리지 않고 알리기만 하며, 추정과 유보는 늘어난 것도 냄
- **`check_meaning.py` 의 `change_rate_level`**: im-not-ai의 30%와 50% 선을 빌렸으나 막지 않고 원문과 다시 대조하라는 신호로만 씀
- **9단계 「고치다 논리를 깬 곳」 하위 항목**: 수정안이 원문에 없던 대구나 결산 꼴을 새로 넣는 역주입. im-not-ai가 자기 윤문 결과에서 실측한 현상임

- **검사기 「상투 문형」(주의)**: 위 표에서 두 표본 모두 0건이던 꼴. 정상 문장 12건을 지어 대 보고 둘(글자 뜻 그대로의 「토대를 다지는 공사」, 주체가 앞에 있는 「~다는 평가입니다」)은 줄만으로 못 갈라 주의로 남김
- **9단계 「구체 경로 없는 결산과 결말 공식」**: 「결국 ~로 이어집니다」, 결말부 시간 부사, 「더 이상」 재정의, 지어낸 은유 겹침

**제외 기준** — 빼는 근거는 사람이 같거나 더 많이 쓴다는 반대 증거뿐임. 두 표본 모두 0건인 꼴을 처음에 뺐다가 2026-10-23 사용자 지적(「앞으로 결함이 나올 수 있는데?」)으로 되돌림

**반영하지 않은 것**

- **고쳐 쓰기 흐름 자체**: 이 저장소는 검사와 판정까지 하고 고치는 판단은 사람과 세션이 함
- **웹 버전**: 외부 모델(업스테이지 Solar)로 돌아 사내 문서를 보낼 수 없음
- **문서 단위 위험도 점수**: 6월 진단에서 인수인계 문서를 `low` 로 판정한 그대로라 정답으로 못 씀

**따로 짚을 것** — 전역 지시 파일의 대구 밀도가 1만 자당 10.6회로 사람 업무 문서의 30배 넘음. 「대체가 아니라 별도로 추가」처럼 고치는 법의 예시로도 이 꼴을 권함. 반복해 읽는 지시 파일의 문체가 응답으로 옮는다는 전역 규칙의 「문체 전염」과 맞물리는 문제라 전역 파일 수정은 사용자 결정으로 넘김.

## 초기 비교 원칙

- **복제 보류**: 기존 도구 코드를 새 저장소에 바로 복사하지 않음
- **같은 입력 사용**: 두 도구와 새 규칙을 같은 진단 표본에 실행
- **사람 판정 우선**: 탐지 건수보다 실제 수정 필요 여부로 정확도 계산
- **장르 분리**: 구조 문서·업무 산문·기술 문서·홍보 문구를 섞지 않음
- **재사용 조건**: 실문서에서 낮은 오탐과 재현 가능한 시험을 확인한 함수만 이관
