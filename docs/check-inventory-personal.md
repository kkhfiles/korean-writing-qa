# 개인 취향 항목 판정

**Opus 재검토에서 「개인」으로 남은 검사 항목** — 항목마다 개인인지 아닌지 판정(전체 목록과 설명: `docs/check-inventory.md`)

**표시하는 법** — 「판정」 칸에 「개인」 또는 「아님」 기재

**개인으로 판정하면** — 이 검사기를 받아 쓰는 다른 사람에게는 기본으로 꺼짐(이 PC에서는 그대로 켜짐)

**검토자** — Fable 5.1, Gemini Argon, Claude(1차) / Opus 재검토: 「표준어인가」가 아니라 「한국 회사의 업무 보고서와 업무 메일에서 그렇게 쓰는가」로 다시 판정(2026-10-20)

**분류 뜻** — 공통: 누구의 업무 문서에서든 걸리는 표현 / 형식: 조직마다 다른 문서 형식 약속 / 개인: 한 사람의 취향이나 특정 문서에만 맞는 수정
