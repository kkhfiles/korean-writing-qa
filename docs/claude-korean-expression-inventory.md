## 바로 쓸 규칙

### 모든 한국어

- **자연스러운 어순**: 영어 문장 구조의 직역 금지
- **낱말 선택**: 불필요한 영어와 드문 낱말 대신 정착된 기술 용어와 흔한 한국어 사용
- **문장 자족성**: 문장만 떼어 읽어도 뜻이 통하는 주어·대상·단위 명시
- **군더더기 제거**: 접속사·수식어·중복을 지워 뜻이 같으면 삭제
- **모호한 지칭 금지**: `우리`·`이들`·`저쪽` 대신 제품명·조직명·역할명 사용
- **평가 수식어 경계**: `가벼운`·`강력한`·`유연한` 대신 실제 동작이나 측정값 제시

### 개조식 참조 문서

- **값 종결**: 명사형 또는 체언
- **절단형 금지**: `코멘트로`·`해당 폴더에`처럼 조사로 끝나는 값 금지
- **라벨 형식**: 한두 어절 명사구 · 의문문과 `내용`·`기타`·`참고`·`비고` 금지
- **반복 라벨**: 같은 칸에는 같은 라벨
- **정보 순서**: 결론·기한·상태 먼저 · 배경·이력·근거 나중
- **진입점**: 첫 줄에 독자가 파악하거나 결정할 내용을 개조식으로 제시

### 업무 문서에서 확인된 표현

- **문서 지점**: `~하는 자리` 대신 지점·위치·사례·단계·시점·대목
- **IT 구성요소**: `부품` 대신 모듈·구성요소 · 이름 번역보다 하는 일 설명
- **진행 단계 군더더기**: `조사 실무 착수` 대신 `조사`
- **독자 교정 어조**: `A로 읽으면 틀림` 대신 알리려던 사실 B를 직접 서술
- **임원 자료 어조**: 구어체·슬로건·은유·마케팅 어조 제외 · 기능·결과·한계 중심
- **제품 메시지**: 정한 용어 유지 · 자리표시자 뒤 `이(가)`·`을(를)` 사용
- **맞춤법 오탐**: `스스로` 정상 표기
