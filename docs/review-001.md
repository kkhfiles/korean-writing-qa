# 규칙·검사기·회귀시험 재검토

**현재 검사기의 신뢰할 수 있는 범위와 남은 빈틈** — 레퍼런스 대조 · 실행 재현 · 독립 검토 · 회귀시험 보강

## 결론

- **현재 실행 범위**: 사용자가 확정한 표현 8개 · `경로` 문맥 분류 · 형식별 본문 추출
- **회귀시험 범위**: 탐지·분류 101건 · 수정 전후 22쌍 · 원본 형식 7개
- **가장 큰 남은 문제**: 수집한 한글 표현 규칙 37개와 외부 규칙 후보는 검사기가 읽지 않음
- **현재 판정**: 활성 검사기의 오탐·누락 회귀 기초는 확보 · 37개 규칙 전체를 보증하는 통합 검사기로 보기에는 부족

## 고친 문제

| 문제 | 재현 증거 | 수정 결과 | 회귀 시료 |
|---|---|---|---:|
| 수정 전·후 문구가 한 줄의 다른 문장에 있으면 실제 오류까지 검사 제외 | `제품화 단계`와 `제품화 경로`가 다른 문장에 함께 있는 문장 | 표·화살표로 명시한 수정 전후 예시만 제외 | 1건 |
| HTML 인라인 태그로 나뉘 표현 누락 | `<div>` 안 `<span>` 사이에 나뉘 `제품화 경로` 미탐지 | 블록 단위로 텍스트 결합 | 1건 |
| 코드 예시 오탐 | Markdown 인라인 코드와 HTML `pre`·`code` 내용 탐지 | 검사 제외 구간으로 처리 | 2건 |
| `두 경로`를 실제 path로 단정 | `제품화에 이르는 두 경로` 오분류 | 수량사 `두`를 실제 path 근거에서 제외 | 1건 |
| `경로를 확인`을 실제 path로 단정 | `승인 경로를 확인` 오분류 | 대상 명사가 없는 `확인`은 사람 검토로 전환 | 1건 |
| `경로에서 벗어났다` 누락 | 에이전트 행동 비유를 사람 검토로 분류 | 조사·활용형 확장 | 1건 |
| 발표자 노트 규칙의 일반 보고서 오용 | 출력에 `scope`만 적고 검사 전에는 미사용 | 실행 시 문서 종류 필수 지정 · 일반 규칙만 공통 적용 | 7건 |
| 실행 대상이 바뀌어도 기존 해시를 기록 | manifest 해시를 검사 없이 결과에 복사 | 실행 직전 파일 해시 대조 · 다르면 중단 | 2건 |
| 한국식 인용 부호 변경 누락 | `「원문」` → `「변경」`이 보호 대조에서 누락 | `「」`·`『』` 문구 보호 | 1건 |

## 2단계 독립 검토

### 합의

- **규칙과 실행 코드 분리**: 37개 규칙 데이터는 필드 검사만 받고 탐지 결과를 바꾸지 못함
- **문서 종류 적용 누락**: 발표자 노트 전용 규칙이 모든 입력에 적용됨
- **표본 출처의 약한 부분**: 149개 중 30개만 model·생성 시각 메타데이터 보유 · 나머지 119개는 전용 원본 파일과 파일명을 근거로 선정
- **실행 재현성**: 입력 149개의 해시는 모두 일치 · 개선한 추출기로 `경로` 68건 재분류 완료
- **의미 보존 한계**: 영문·숫자·인용문은 기계 대조 가능 · 한글 고유명사 변경은 자동 판정 불가

### 충돌

- **판단 충돌 없음**: 독립 검토의 핵심 지적과 같은 문제를 재현
- **수치 차이**: 독립 검토 중간 결과는 실제 path 60건·사람 검토 7건 · `경로를 확인`의 과대 분류를 추가로 고친 뒤 59건·8건으로 확정

### 새로 확인한 문제

- **새 저장소 복제본의 주석 검사 누락**: 원문이 Git 제외라 `test_annotation_spans.py`가 전부 건너뜀 · 커밋된 수정 전후 쌍의 보호 토큰 검사는 따로 실행
- **외부 검사기 판정 연결 누락**: 25건을 21건·4건으로 분류한 요약은 있지만 각 탐지 결과와 사람 판정의 연결 자료는 커밋된 파일에 없음
- **다중 형식 외부 검사 미지원**: `run_existing_tools.py`는 `documents` manifest만 읽어 `diagnostic-003`의 `units` 구조를 처리하지 못함

## 검증 결과

- **자동 시험**: 60건 전부 통과
- **입력 해시**: `diagnostic-003` 149개 전부 일치
- **`경로` 재실행**: 68건 · 추상 후보 1건 · 실제 path 후보 59건 · 사람 검토 8건
- **문서 구조 검사**: 변경 문서 오류 0건 · 반복 블록 라벨 불일치 주의 2건은 각 절의 일회성 요약으로 확인
