# 문제로 보는 것 — 점검표

**사용자 기준과 검사기 기준이 맞는지 가르는 표** — 문장 52개 · 맨 오른쪽 「판정」 칸을 채우면 됨 · 칸에 적기 어려우면 번호와 ○·×만 대화로 알려 주셔도 됨

- **판정 칸에 적을 것**: ○ 고칠 것 · × 그대로 둠 · △ 경우에 따라
- **1층**: 전역 검사기(설치본과 같은 버전) · 문장을 목록 한 줄로 넣고 돌린 결과 · 괄호는 지적 갈래
- **단어 점검**: 업무 글 기준선에서 드문 낱말로 목록에 오르면 ○
- **2층**: CLAUDE.md 없는 호출(Opus) · 사용자 기준 판정문(「업무 보고서에서 한국인이 잘 쓰지 않는 말인가」) · 볼 곳을 알려 주지 않고 판정하게 함 · ○는 볼 곳을 짚은 것 · 「그 밖」은 다른 어절을 짚은 것
- **제 판정**: 지금 제가 기준으로 삼는 것 · 「모름」은 제가 가르지 못한 것
- **문장 출처**: 기술 조사 보고서 검토에서 고친 문장 · 이 저장소와 다른 저장소 문서의 문장을 일반 표현으로 바꾼 것 · 지어낸 대조 문장
