# 한글 문서 최종화 스킬 구현 결과

**Claude Code·Codex 한글 문서 최종화** — 편집 원본 검사 · 문맥 윤문 · 의미 보존 · 피드백 회귀시험을 한 스킬로 연결

## 설치 결과

| 항목 | 결과 |
|---|---|
| 정본 | `C:/Users/<사용자>/.claude/skills/finalize-korean-document/` |
| Codex 사용 | 정본을 가리키는 junction 설치 |
| Claude Code 자동 검사 | 문서 수정 직후와 발행 직전에 실행 |
| Codex 자동 검사 | `apply_patch`·`Edit`·`Write` 직후 실행 |
| 자동 수정 | 사용 안 함 · 검사 결과만 현재 세션에 전달 |
| 외부 과금 API | 사용 안 함 |

## 처리 순서

1. 문서 종류와 편집 원본 선택
2. 사용자 확정 표현과 `경로` 은유 후보 검사
3. 현재 세션의 모델이 문서 목적과 앞뒤 문맥 확인
4. 필요한 문장만 수정
5. 숫자·식별자·인용문·코드·URL·지정 고유명사 보존 확인
6. 같은 검사 재실행
7. 새 사용자 피드백을 규칙과 회귀 시료로 함께 기록

## 지원 원본

**직접 검사**: Markdown · HTML · 일반 텍스트 · JSON · JSONL · YAML · properties

**변환 산출물**: PDF보다 편집 원본 우선 · Word와 PowerPoint를 직접 만든 경우 표시 문구 추출 후 검사
