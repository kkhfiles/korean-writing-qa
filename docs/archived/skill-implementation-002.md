# 한글 문서 최종화 스킬 2차 보강

**사용자 교정을 후보로 수집하고, 사람 판단과 회귀시험을 통과한 표현만 실제 검사 규칙에 반영하는 흐름**

## 보강 결과

| 항목 | 결과 |
|---|---|
| 시료 집계 | 탐지·분류 68건 · 의미 보존 17건 · 자연스러움 기준문 13쌍을 별도 표기 |
| 자연스러움 기준문 | 원본 한 줄·행 번호·문서 해시 보존 · 자동 자연스러움 합격 건수 0 |
| 피드백 수집 | 실제 규칙을 바꾸지 않는 후보 목록에 기록 |
| 규칙 반영 | 사람 판단이 있는 후보만 허용 · 자체 시험 실패 시 복원 |
| 사본 관리 | 실행 스킬과 QA 저장소의 규칙·시료를 함께 갱신 · 작업 전후 일치 확인 |
| 외부 과금 API | 사용 안 함 |

## 피드백 생애주기

1. **관찰**: 모델이 찾은 표현 · `observed` 저장 · 승격 불가
2. **확인**: 사용자 직접 수정·사용자 수락·사람 검토 · `confirmed` 저장
3. **시험**: 양성·권장·설명·범위 밖 시료 생성 · 탐지와 의미 보존 시험
4. **활성화**: 시험 통과 후 `active` 저장 · 실패 시 후보와 두 사본 모두 복원

**시험 중간 상태**: 영구 저장 안 함 · 시험 완료 전 활성 처리 금지 · 실패 시 확인 상태로 복원

## 문맥 저장 기준

| 범위 | 저장 내용 |
|---|---|
| 독립 문장 | 수정 전후 표현 |
| 앞뒤 문장 필요 | 판단에 쓴 앞문장 또는 뒷문장 |
| 표·목록·슬라이드 | 절 제목·논리 위치·판단에 쓴 구조 한 줄 |
| 문서 전체 필요 | 원본 참조와 해시 · 문서 전체 사본은 기본적으로 저장하지 않음 |

**문맥 길이**: 고정 안 함 · 수정 판단에 실제로 쓴 정보만 저장
